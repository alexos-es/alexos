# AlexOS · Identidad editorial

Paleta aprobada: carbón #292831, marfil #EAE8E3, terracota #B28E77; secundarios pizarra #77717C y gris #C6C3C1.
Lora para titulares y wordmark; Inter para interfaz y cuerpo. Fuentes locales con licencia OFL.

El archivo emblema-original.png es una copia binaria del original. Ningún trazo, letra ni trenzado se ha redibujado, recortado o recoloreado. Las exportaciones solo escalan proporcionalmente el conjunto y añaden margen/fondo. No se ha inventado un símbolo reducido: se conserva el emblema íntegro también en los iconos, cuya legibilidad debe valorarse a tamaño pequeño.

- avatar-1080.png: Instagram y avatar de alta resolución.
- avatar-400.png: LinkedIn, GitHub y otros perfiles cuadrados; margen apto para recorte circular.
- linkedin-cover-1584x396.png: portada de LinkedIn (comprobar el recorte en cada dispositivo).
- social-1200x630.png: vista al compartir enlaces.
- apple-touch-icon.png: acceso directo Apple, 180 px.
- icon-192.png e icon-512.png: iconos web.
- favicon.ico: 16, 32, 48 y 64 px.
- wordmark-transparente.png: alexos en Lora; uso horizontal.
- emblema-transparente-512.png: emblema con margen transparente.

El original tiene 250 × 250 píxeles: ampliar la exportación no añade detalle vectorial. Para imprenta o gran formato se necesita el maestro vectorial original.
